# Yandere Simulator สำหรับ Android
Yandere Simulator เป็นเกมแนวลอบเร้นที่ให้ผู้เล่นสวมบทบาทเป็นเด็กสาวที่คอยสะกดรอยตามเด็กหนุ่มและแอบกำจัดเด็กสาวคนอื่นที่มีใจให้เขา โดยต้องคอยรักษาภาพลักษณ์ของนักเรียนหญิงผู้ใสซื่อบริสุทธิ์เอาไว้ด้วย
# ฉันทำได้อย่างไร
ฉันใช้โปรแกรม [**AssetStudio 2.4.0+ (2025 Update)**](https://github.com/Razviar/assetstudio.git) ในการแกะ assets ของเกม และโปรแกรม [**ILSpy**](https://github.com/icsharpcode/ILSpy.git) ในการ Decompile ไฟล์ .dll ซึ่งเป็นโค้ด C# ของเกม กับโปรแกรม Unity 2019 ในการดัดแปลงเกมขึ้นมาใหม่ให้เข้ากันกับ Android
# วิธีดาวน์โหลด
ดาวน์โหลดได้ใน [releases](https://github.com/S4ad0wKhab/yandere-simulator-for-android/releases) เลื่อนลงและหาข้อความสีน้ำงิน:

* ys_2025.apk <== เกมหลัก
* pose_mod.apk <== Yandere Simulator เวอร์ชั่น Pose Mod (เร็วๆนี้)
